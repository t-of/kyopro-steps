# kyopro-steps — 競プロの技法をステップ実行で学ぶ

競技プログラミングの技法を、コードを1行ずつ動かしながら学べるサイト。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/kyopro-steps/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

目次から章・項目を選ぶ。項目ページでは、解説 → ステップ実行の図（◀ 前へ / 次へ ▶ / 自動再生 / 最初に戻す で動かす）
→ 例題 → 解答（開閉できる）の順に並ぶ。まだ中身のない項目は「準備中」と出る。
章ファイルの足し方は [CLAUDE.md](CLAUDE.md) を見る。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
